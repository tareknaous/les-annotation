Guidelines

Each item shows a conversation, the assistant's latest response, and the message the user actually sent next. Your job is to infer how the user felt about that response — not how good you think it is in the abstract. The user's next message is your main evidence: a user who simply moves on was probably satisfied enough; a user who repeats or rephrases the request probably was not.

1. Instruction followed

  • Yes — did what the user asked.
  • Partially — did some of it, or did it with notable gaps.
  • No — did not do what was asked.

2. Reaction type

  • Critique — the user's next message contains explicit pushback, corrections, or complaints.
  • Praise — it contains explicit gratitude, compliments, or expresses satisfaction.
  • Neutral — a follow-up question, a topic shift, or just moving on without any explicit critique or praise.

Reaction type is about what the message says. A user can be unhappy and still write a Neutral message.

3. Rating (from the user's point of view)

  1. Bad — produced a completely irrelevant response to what the user asked
  2. Poor — the response contains a few important flaws that need revision
  3. Acceptable — missed a few minor things
  4. Good — performed the task like the user asked
  5. Perfect — flawless execution

4. AI's guess (step 2)

After you save step 1, you will see what an AI system guessed the user was thinking, and rate how plausible it is. Your step 1 answers are locked at that point, so please answer step 1 on your own first.

Conversations come from real, public chatbot logs and can be messy, terse, or off-topic. Judge them as they are.
